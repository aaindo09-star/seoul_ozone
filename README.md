# 서울 오존 노출 분석 대시보드 (팀 오존 랩)

서울의 광화학 오존이 어떤 조건에서 높아지고, 그때 사람과 식물이 얼마나 노출되는지 보여 주는 Streamlit 웹앱입니다.

## 파일
- `ozone_dashboard.py` : 웹앱 코드 (데이터 불러오기 → 사이드바 → 분석 화면)
- `requirements.txt` : 필요한 라이브러리
- `ozone_hourly.csv` : 시간별 자료 (서울 도시대기 25개 측정소, 2023~2025년 5~9월, 오존 + 기상)
- `README.md` : 이 설명

## 데이터 출처
- 한국환경공단 에어코리아, 최종확정 측정자료 (공공누리 제3유형: 출처표시·변경금지). 이 저장소의 CSV는 원자료를 가공한 것입니다.
- 기상청 기상자료개방포털, 종관기상관측(ASOS) 서울(지점 108) 시간 자료 (공공누리 출처표시).

## 기준값과 출처
| 기준 | 값 | 출처 |
|---|---|---|
| 오존주의보/경보/중대경보 | 1시간 평균 0.12/0.3/0.5 ppm 이상 | 서울시 대기환경정보 (cleanair.seoul.go.kr/information/info13) |
| 오존 환경기준 | 1시간 평균 0.1 ppm 이하, 8시간 평균 0.06 ppm 이하 | 환경정책기본법 시행령 별표 1 (국가법령정보센터) |
| AOT40 정의 | 낮 시간 40 ppb 초과분의 누적 | EEA, UNECE |
| AOT40 임계값 | 작물 3 ppm·h(3개월), 산림 5 ppm·h(6개월) | UNECE 2010 (APIS 인용) |

## 처리 요약
- 하루 유효 측정 시간이 75% 미만인 날 제외, 연속 2시간 이하 빈 구간만 앞뒤 값으로 보정
- 음수·0.5 ppm 초과·24시간 이상 같은 값 반복은 측정 오류로 보고 빈 값 처리
- 월·시간대별 IQR로 이상치 후보를 표시 (주의보 수준 값은 지우지 않음)
- 낮 시간 = 08~20시, 사람 활동 시간 = 09~16시 (모두 시작 시각 기준)

## 한계
일부 측정소와 관측소 한 곳의 자료이며, 측정소 농도는 개인이 실제 마신 양이 아닙니다. AOT40은 유럽 기준을 참고한 지표입니다.
